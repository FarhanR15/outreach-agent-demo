Campaign

The sequence approved leads land in. It is created in Instantly as a draft — you press Launch there yourself.

◆ Nothing sends from this screen. There is no code path in this project that calls Instantly's activate endpoint. The campaign is created paused, then read back to confirm it is still a draft before any lead is uploaded.

What this proxy misses

The things that actually define your ICP — revenue, program price, audience size, ad budget — are not filterable in Apollo. It only knows job title, industry, company size and location. Those deeper signals are judged later by the qualifier, from their LinkedIn bio, recent posts and website.
